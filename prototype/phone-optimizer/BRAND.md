# بهینه | Behine — راهنمای برند (Brand Guide) v0.1

## لوگو
- علامت: حرف **B** روی گرید **۶×۱۱** از نقاط LED (واحد فاصله = ۱۱px، شعاع نقطه = ۴px)
- رنگ نقاط: سفید `#F5F5F5` + نوار میانی قرمز `#E62929`
- نسخه‌ی مونوکروم: همه‌ی نقاط سفید
- فاصله‌ی امن: ۱ واحد نقطه از هر طرف · حداقل ارتفاع: ۱۴px وب / ۲۰px اپ
- ممنوع: چرخش، کشش، تغییر رنگ (جز قرمز/سفید)، قراردادن روی پس‌زمینه‌ی روشن/شلوغ

## تایپوگرافی
- **Display:** DotGothic16 — فقط اعداد/وضعیت (ساعت، امتیاز، درصد، ظرفیت)
- **بدنه:** Vazirmatn (فارسی) · Inter (لاتین)
- **تیتر لاتین:** حروف‌بزرگ + letter-spacing ~0.08em

## قواعد بصری
1. مشکی خالص پایه است؛ عمق با لایه‌های خاکستری ساخته می‌شود، نه گرادیان رنگی
2. در هر صفحه فقط یک رنگ برجسته: قرمز برند
3. خطوط جداکننده نقطه‌چین (`dotted`) = امضای Nothing
4. نمودارها میکرو: خط ۱٫۶px + نقطه پایانی درخشان + پیش‌بینی خط‌چین + کپشن یک‌خطی
5. آیکون‌ها مونوکروم (grayscale) و اکشن اصلی قرمز
